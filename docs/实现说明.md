# 实现说明 — #1506 经营数据 Agent

## 需求还原

企业知识库与多 Agent 协作系统（系列 50 单）的拆单之一。本单范围：
**配置经营指标查询和分析 Bot，区分事实、计算与建议**。

验收标准：**提供匿名指标输入、计算校验及分析示例**。

## 设计

### 1. 指标配置模板

`schema/metric_config.schema.json`（draft-07）定义指标配置：
- `metric_id`（唯一，`metric-` 前缀）
- `name` / `category`（六类枚举）/ `definition`
- `calculation_type`（sum/average/ratio/count/delta/custom）
- `data_input_schema.x/y`（CSV 列名，x=主量，y=数量因子或分母）
- `output_kind`（fact/calculation/suggestion 三档）
- `formula` / `suggestion_rule` / `anonymized_note`

### 2. 三分输出（对应"区分事实、计算与建议"）

| 输出 | 含义 | 来源 |
|---|---|---|
| `fact` | 原始事实，不加工 | 输入记录数 + 样例行 |
| `calculation` | 复算值，可校验 | 按 calculation_type 计算 |
| `suggestion` | 建议，基于规则 | 趋势 + suggestion_rule |

三者严格分开：事实不加价值判断，计算可对账，建议才带业务判断。

### 3. 计算校验（验收核心）

`verify(metric_id, inputs, expected)` 复用 `_calculate()` 复算，
返回 `(ok, actual, expected)`。测试 5 断言周营收=1270（Σ 单价×数量），
测试 6 断言错误预期（999999）判 FALSE——证明"计算校验"是真的，
不是只看机器输出。

### 4. 实现修复记录（测试抓到的真 bug）

- **CSV 字符串数值化**：`csv.DictReader` 读出的数字是字符串，原
  `isinstance(r[k], (int, float))` 全 False 导致 sum=0。修复为统一
  `_num()` 转换。
- **sum 按乘积求和**：营收=Σ(unit_amount × qty)，原实现只 Σ 单价。
  修复为存在 y 时按 `x*y` 求和，与 formula 声明一致。

### 5. 匿名合规

样例全部为脱敏模拟数据；每个指标配置带 `anonymized_note` 显式声明，
无真实客户/金额/机密。
